С чего начать?

Путь в Python Web-разработку можно разделить на несколько последовательных этапов. Необязательно изучать всё сразу.

Roadmap

Пошаговый путь

Последовательное изучение помогает не перегружать себя большим количеством новых технологий.

1

Изучите основы Python

Перед изучением веб-фреймворков желательно уверенно владеть базовым синтаксисом Python, функциями, классами, коллекциями, исключениями и модулями.

  • переменные и типы данных;
  • условия и циклы;
  • функции;
  • классы и ООП;
  • работа с модулями и пакетами.
2

Разберитесь с HTML и CSS

Даже если backend является основной специализацией, понимание HTML и CSS помогает лучше представлять, как браузер взаимодействует с сервером.

  • структура HTML-документа;
  • семантические элементы;
  • формы;
  • CSS-селекторы;
  • адаптивная вёрстка.
3

Изучите HTTP

Веб-разработка невозможна без понимания того, как браузер и сервер обмениваются данными.

  • HTTP-запросы и ответы;
  • методы GET, POST, PUT, DELETE;
  • коды состояния HTTP;
  • заголовки;
  • JSON.
4

Выберите фреймворк

После базовой подготовки можно перейти к одному из Python-фреймворков.

Django

Полноценные веб-приложения.

Flask

Простые и гибкие приложения.

FastAPI

API и backend-сервисы.

5

Создайте небольшой проект

После изучения теории важно перейти к практике. Хорошим первым проектом может стать простой блог, список задач, каталог или REST API.

Подготовка

Настройка окружения

Для начала работы достаточно Python и редактора кода.

Создание виртуального окружения

Виртуальное окружение позволяет изолировать зависимости конкретного проекта. 

python -m venv .venv

После создания окружения его необходимо активировать перед установкой библиотек.

Установка Flask

Например, Flask можно установить с помощью менеджера пакетов pip. 

pip install flask

Аналогичным способом устанавливаются необходимые зависимости других проектов.

Первый проект

Начните с простого приложения

Необязательно сразу создавать сложную систему. Лучше начать с небольшого приложения, в котором можно последовательно реализовать несколько основных возможностей.

  1. Создать главную страницу.
  2. Добавить несколько маршрутов.
  3. Передавать данные в шаблон.
  4. Подключить базу данных.
  5. Добавить форму. 
from flask import Flask

app = Flask(__name__)


@app.route("/")
def home():
    return "Hello, Python Web!"


if __name__ == "__main__":
    app.run(debug=True)
