О PyWeb

Учебный сайт о современных Python-фреймворках для веб-разработки.

Идея проекта

Зачем создан PyWeb?

Python используется не только для анализа данных, машинного обучения и автоматизации. Этот язык также широко применяется при создании веб-приложений и серверных систем.

Однако начинающему разработчику бывает сложно понять, какой именно фреймворк выбрать для своего проекта. Django, Flask и FastAPI решают похожие задачи, но отличаются архитектурой, набором возможностей и областью применения.

Цель PyWeb — в простой и наглядной форме познакомить пользователя с этими технологиями и помочь определить, какая из них лучше подходит для конкретной задачи.

Технологии сайта

Как создан PyWeb?

При разработке сайта использовались стандартные технологии фронтенд-разработки и CSS-фреймворк Bootstrap.

Bootstrap используется для построения сетки, адаптивной навигации, кнопок, карточек и других элементов интерфейса. Дополнительные стили находятся в отдельном файле CSS.

Bootstrap сетка и готовые UI-компоненты
