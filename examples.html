Практика

Примеры проектов

Лучше всего возможности фреймворка становятся понятны на практике. Рассмотрим несколько идей проектов для Django, Flask и FastAPI.

Практические идеи

От простого к сложному

Начинать обучение лучше с небольших проектов, постепенно добавляя новые возможности.

Django

Интернет-магазин

Учебный интернет-магазин позволит познакомиться с моделями, базой данных, пользователями, формами и административной панелью Django.

Что можно реализовать?

  • каталог товаров;
  • регистрацию пользователей;
  • корзину;
  • заказы;
  • поиск товаров.
Flask

Мини-блог

Flask хорошо подходит для создания небольшого блога, где можно самостоятельно спроектировать структуру приложения.

Что можно реализовать?

  • список публикаций;
  • страницу отдельной статьи;
  • создание публикаций;
  • комментарии;
  • простую авторизацию.
FastAPI

REST API

API для списка задач — простой проект, позволяющий разобраться с маршрутами, HTTP-методами и JSON.

Что можно реализовать?

  • получение списка задач;
  • создание задачи;
  • изменение задачи;
  • удаление задачи;
  • автоматическую документацию.

Django

Пример маршрута Django

В Django URL связывается с представлением, которое обрабатывает запрос пользователя.

В реальном проекте представление может получать данные из базы, обрабатывать форму и возвращать HTML-шаблон. 

from django.http import HttpResponse


def home(request):
    return HttpResponse(
        "Добро пожаловать в PyWeb!"
    )
Flask

Пример маршрута Flask

Flask позволяет очень быстро создать маршрут и определить функцию, которая будет обрабатывать запрос.

Благодаря минимальному количеству встроенных компонентов разработчик может самостоятельно выбирать дополнительные библиотеки. 

from flask import Flask

app = Flask(__name__)


@app.route("/")
def home():
    return "Hello, Flask!"
FastAPI

Пример API на FastAPI

FastAPI позволяет описывать API с использованием аннотаций типов. На их основе фреймворк может выполнять проверку входных данных.

После запуска приложения разработчик также получает интерактивную документацию API. 

from fastapi import FastAPI

app = FastAPI()


@app.get("/hello")
def hello():
    return {
        "message": "Hello, FastAPI!"
    }
План развития

Как усложнять проект?

1

Начальный уровень

Несколько страниц, маршруты, простые формы и обработка данных.

2

Средний уровень

База данных, авторизация пользователей, API и работа с внешними сервисами.

3

Продвинутый уровень

Тестирование, Docker, кэширование, асинхронность и развёртывание.

Какой проект выбрать?

Если вы изучаете Python Web впервые, начните с небольшого приложения. Главное — не количество функций, а понимание того, как работает веб-приложение.
