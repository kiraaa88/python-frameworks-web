OVERVIEW

Что такое Django?

Django — это высокоуровневый веб-фреймворк с открытым исходным кодом, написанный на Python. Он предназначен для разработки безопасных, масштабируемых и функциональных веб-приложений.

Django предоставляет разработчику большое количество готовых компонентов: систему маршрутизации, ORM, формы, аутентификацию, административную панель и механизмы защиты от распространённых веб-атак.

Фреймворк придерживается принципа «Don't Repeat Yourself» (DRY), который позволяет уменьшить дублирование кода и упростить сопровождение проекта.

ARCHITECTURE

Архитектура Django

Django использует архитектурный подход MVT (Model — View — Template), который разделяет данные, логику обработки запросов и представление.

01

Model

Отвечает за структуру данных и взаимодействие с базой данных.

02

View

Содержит логику обработки HTTP-запросов и формирования ответа.

03

Template

Определяет структуру HTML-страницы, которая отображается пользователю.
