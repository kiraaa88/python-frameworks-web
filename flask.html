Flask

Лёгкий и гибкий микрофреймворк Python, предоставляющий разработчику свободу выбора компонентов приложения.

F
OVERVIEW

Что такое Flask?

Flask — это лёгкий веб-фреймворк для Python, предназначенный для создания веб-приложений и API. Он относится к категории микрофреймворков.

В отличие от Django, Flask предоставляет разработчику минимальный набор компонентов. Дополнительные возможности подключаются отдельно в зависимости от требований проекта.

Такой подход позволяет разработчику самостоятельно выбирать архитектуру приложения, библиотеки для работы с базами данных, аутентификацию и другие компоненты.

FEATURES

Основные особенности

Минимализм

Небольшое ядро позволяет начать разработку с минимальным количеством компонентов.

Гибкость

Разработчик самостоятельно выбирает дополнительные библиотеки и инструменты.

Расширения

Функциональность Flask можно расширять с помощью специальных расширений.

Быстрый старт

Простейшее приложение можно создать всего за несколько строк Python-кода.

ARCHITECTURE

Как устроен Flask?

Flask использует минималистичный подход. Основой приложения является объект Flask, который отвечает за обработку маршрутов и HTTP-запросов.

01

Route

Определяет URL-адрес и функцию, которая должна быть вызвана при соответствующем запросе.

02

View Function

Обрабатывает запрос пользователя и формирует HTTP-ответ.

03

Extension

Дополнительные библиотеки позволяют добавить работу с базами данных, авторизацию и другие возможности.

CODE EXAMPLE

Пример Flask-приложения

Минимальное Flask-приложение может выглядеть следующим образом: 

from flask import Flask

app = Flask(__name__)


@app.route("/")
def home():
    return "Hello, Flask!"


if __name__ == "__main__":
    app.run(debug=True)

Преимущества

  • Простота изучения
  • Минималистичная архитектура
  • Высокая гибкость
  • Быстрое создание небольших приложений
  • Большое количество расширений

Недостатки

  • Меньше встроенных возможностей
  • Архитектуру необходимо продумывать самостоятельно
  • Дополнительные компоненты требуют отдельных библиотек
  • Для крупных проектов может потребоваться больше настроек
