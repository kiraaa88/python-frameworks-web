# PyWeb — Python-фреймворки для Web-разработки

Учебный адаптивный сайт о Django, Flask и FastAPI. Автор: Косолапова Карина Андреевна, группа 141-ПМо.

## Технологии
HTML5, CSS3, Bootstrap 5.3.3, Bootstrap Icons 1.11.3, JavaScript.
Bootstrap и иконки загружаются через CDN: для полного оформления нужен интернет.

## Запуск
Откройте `index.html` в браузере либо запустите в папке проекта:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000. Также можно использовать Live Server в VS Code.

## Страницы
Главная, Django, Flask, FastAPI, сравнение, выбор фреймворка, начало обучения, примеры, ресурсы, о проекте — всего 10 страниц.

## Возможности
Общее меню и подвал, сайдбар на каждой странице, адаптивная сетка, WebP с srcset и sizes, семантические таблицы, видео RuTube и форма выбора фреймворка. Форма работает локально и не отправляет данные.

## Публикация на GitHub Pages
1. Загрузите содержимое этой папки в репозиторий GitHub (index.html в корне).
2. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root).
3. Сохраните настройки и дождитесь публикации.
4. Вставьте полученный адрес сайта в первую строку README.md и в read.md.
5. Добавьте адрес репозитория в read.md и в раздел ниже.
